## Документация: Система системных сообщений и липких дат

# Обзор

Пакет SystemMessages предоставляет готовые компоненты для:
Компонент | Назначение
StickyDateProvider | Контекст-провайдер: управляет логикой прилипания дат к верху при скролле
StickyDateHeader | Визуальный компонент: отображает "липкую" дату в верхней части чата
SmartDateSeparator | Умный сепаратор: регистрируется в контексте, определяет видимость
DateSeparator | Презентационный сепаратор: отображает дату в потоке сообщений
SystemMessage | Отображение системных событий (вход/выход пользователя, создание чата и т.д.)

Ключевые фичи:
✅ Плавное прилипание маркеров дат при скролле (как в Telegram/WhatsApp)
✅ Автоматическое скрытие инлайн-сепараторов при активации липкого хедера
✅ Поддержка локализации дат (Сегодня, Вчера, 24 марта 2026)
✅ Плавные анимации появления/исчезновения (0.2–0.25с)
✅ Оптимизированная производительность: requestAnimationFrame, пассивные слушатели

Компоненты
<StickyDateProvider>
Контекст-провайдер для управления липкими датами. Оборачивает список сообщений и предоставляет логику скролла.
Props

Prop | Тип | Обязательный | Описание

children | React.ReactNode | ✅ | Дочерние компоненты (список сообщений)

containerRef | React.RefObject<HTMLDivElement> | ❌ | Внешний реф на скролл-контейнер. Если не передан — создаётся внутренний

Контекст (через useStickyDate)

const { registerSeparator, unregisterSeparator, activeDate, isActive, isHidden } = useStickyDate();

Метод/Значение | Тип | Описание

registerSeparator(id, date, element) | (string, Date, HTMLElement) => void | Зарегистрировать сепаратор в реестре

unregisterSeparator(id) | (string) => void | Удалить сепаратор из реестра

activeDate | Date | null | Текущая активная дата для липкого хедера

isActive(id) | (string) => boolean | Является ли сепаратор активным (показывается в хедере)

isHidden(id) | (string) => boolean | Должен ли сепаратор быть скрыт

Пример:
<StickyDateProvider>

  <div className="scroll-container">
    {/* Сообщения и сепараторы */}
  </div>
</StickyDateProvider>

// С внешним контейнером
const scrollRef = useRef<HTMLDivElement>(null);
<StickyDateProvider containerRef={scrollRef}>
{/_ ... _/}
</StickyDateProvider>

<StickyDateHeader>
Визуальный компонент липкого заголовка даты. Отображает дату, прилипшую к верху чата.
Props: 
Prop | Тип | По умолчанию | Описание

date | Date/null | — | Дата для отображения
isVisible | boolean | false | Видим ли хедер (управляет анимацией)
className | string | '' | Дополнительные CSS-классы

CSS-классы (модуль)

Класс | Назначение
.stickyHeader | Базовый контейнер: position: absolute, анимации
.stickyHeader.visible | Видимое состояние: opacity: 1
.stickyHeader.hidden | Скрытое состояние: opacity: 0
.headerContent |Внутренний блок с фоном и скруглением

Пример

<StickyDateHeader
date={new Date('2026-03-24T10:00:00')}
isVisible={true}
/>
// Рендерит: "Сегодня" с анимацией появления

<SmartDateSeparator>
Умный сепаратор даты. Автоматически регистрируется в контексте и определяет свою видимость.
Props:

Prop | Тип | Обязательный | Описание

id | string | ✅ | Уникальный идентификатор сепаратора
date | Date | ✅ | Дата для отображения
className | string | ❌ | Дополнительные CSS-классы

Как работает
1.При монтировании вызывает registerSeparator(id, date, element)
2.При размонтировании вызывает unregisterSeparator(id)
3.Вычисляет shouldBeHidden = isHidden(id) || isActive(id)
4.Передаёт isHidden в DateSeparator для визуального скрытия

Пример
<SmartDateSeparator
id="separator-1234567890-0"
date={new Date('2026-03-24')}
/>

💡 Важно: id должен быть уникальным. Рекомендуемый формат:
separator-${timestamp}-${index}

<SystemMessage>
Компонент отображения системных событий. Рендерит текст уведомления в зависимости от типа события.

Prop | Тип | Обязательный | Описание

Message | SystemMessageData | ✅ | Объект системного сообщения
className | string | '' | Дополнительные CSS-классы

Структура SystemMessageData

interface SystemMessageData {
id: string;
type: MessageType.SYSTEM;
eventType: SystemEventType; // См. таблицу ниже
eventData: {
payload: ChatCreatedData | MemberJoinedData | ...;
timestamp: number;
};
createdAt: Date;
}

Типы событий (SystemEventType)

Значение | Описание | Пример вывода
CHAT_CREATED | Создана группа | Иван создал группу «Работа»
CHANNEL_CREATED | Создан канал | Иван создал канал «Новости»
MEMBER_JOINED | Пользователь присоединился | Анна присоединяется к группе
MEMBER_INVITED | Пользователь приглашён | Иван пригласил в группу Анна
MEMBER_LEFT | Пользователь покинул | Анна покинула группу
MEMBER_KICKED | Пользователь удалён | Иван удалил из группы Анна
CHAT_NAME_CHANGED | Название изменено | Иван изменил название чата с «Старое» на «Новое»
MESSAGE_PINNED | Сообщение закреплено | Иван закрепил сообщение

CSS-классы

Класс | Назначение

.systemMessage | Контейнер: центрирование, отступы
.messageWrapper | Фон, скругление, паддинги
.highlight | Выделение имён пользователей (жирный, белый цвет)

Пример:
<SystemMessage
message={{
    id: 'sys-123',
    type: MessageType.SYSTEM,
    eventType: SystemEventType.MEMBER_JOINED,
    eventData: {
      payload: { userName: 'Анна', joinType: 'self' },
      timestamp: Date.now()
    },
    createdAt: new Date()
  }}
/>
// Рендерит: <span>Анна присоединяется к группе</span>

Пример использования
Базовый сценарий: список сообщений с датами

// MessagesList.tsx
import { useMemo } from 'react';
import { StickyDateProvider } from '@/entities/Chat/ui/SystemMessages/context/StickyDateContext';
import { SmartDateSeparator } from '@/entities/Chat/ui/SystemMessages/ui/SmartDateSeparator/SmartDateSeparator';
import { shouldShowDateSeparator } from '@/entities/Chat/model/lib/service/dateFormating/dateFormater';

export const MessagesList = ({ messages }) => {
// Вставляем сепараторы между сообщениями разных дат
const messagesWithSeparators = useMemo(() => {
const result = [];

    messages.forEach((message, index) => {
      const prev = messages[index - 1];

      // Проверяем: нужна ли вставка сепаратора?
      if (shouldShowDateSeparator(message.createdAt, prev?.createdAt)) {
        result.push({
          type: 'separator',
          id: `separator-${message.createdAt.getTime()}-${index}`,
          date: message.createdAt
        });
      }

      result.push({ type: 'message', data: message });
    });

    return result;

}, [messages]);

return (
<StickyDateProvider>

<div className="message-list">
{messagesWithSeparators.map(item => {
if (item.type === 'separator') {
return (
<SmartDateSeparator 
                key={item.id} 
                id={item.id} 
                date={item.date} 
              />
);
}

          // Рендер обычных или системных сообщений...
          return <Message key={item.data.id} {...item.data} />;
        })}
      </div>
    </StickyDateProvider>

);
};

Локализация дат
Функция formatDateSeparator автоматически форматирует даты:

import { formatDateSeparator } from '@/entities/Chat/model/lib/service/dateFormating/dateFormater';

formatDateSeparator(new Date()); // "Сегодня"
formatDateSeparator(new Date(Date.now() - 86400000)); // "Вчера"
formatDateSeparator(new Date('2026-03-24')); // "24 марта"
formatDateSeparator(new Date('2025-03-24')); // "24 марта 2025"

Настройка локали
По умолчанию используется ru-RU. Для изменения:

// В dateFormater.ts
new Intl.DateTimeFormat('en-US', { /_ options _/ })

Форматы

Условие | Формат | Пример
Сегодня | строка | "Сегодня"
Вчера | строка | "Вчера"
Текущий год | d MMMM | "24 марта"
Прошлый год | d MMMM yyyy | "24 марта 2025"

Константы конфигурации

Настройте поведение в StickyDateContext.tsx:

const STICKY_OFFSET_TOP = 10; // Отступ липкого хедера от верха (px)
const STICKY_TOLERANCE = 30; // Допуск для раннего переключения даты (px)
const SCROLL_DEBOUNCE_MS = 50; // Задержка перед обработкой скролла (мс)

Параметр | Меньшее значение | Большее значение

STICKY_OFFSET_TOP | Хедер ближе к краю | Хедер ниже
STICKY_TOLERANCE | Переключение точно при пороге | Переключение заранее
SCROLL_DEBOUNCE_MS | Более отзывчивый скролл | Меньше нагрузка на CPU
