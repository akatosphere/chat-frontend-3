📦 System Messages & Date Separators
Компоненты для отображения системных событий и разделителей дат в чате.

# Компоненты

Компонент | Описание
SystemMessage | Отображает системные события: создание чата, приглашение, закрепление и т.д.
DateSeparator | Разделитель дат в потоке сообщений (невидимый маркер для Observer)
StickyDateHeader | Фиксированный заголовок даты вверху чата при скролле
MessagesList | Контейнер-обёртка с логикой IntersectionObserver

# SystemMessage

Отображает системные события чата в виде центрированной плашки.

**Props**
interface SystemMessageProps {
message: SystemMessageData; // Обязательный проп с данными события
className?: string; // Дополнительные CSS-классы
}

**Поддерживаемые события**

Событие | Пример отображения
CHAT_CREATED | 👤 Анна Петрова создала группу «Планирование 2024»
MEMBER_JOINED | 👤 Влад Ляшев присоединяется к группе
MEMBER_INVITED | 👤 Анна Петрова пригласил(а) в группу Инна Георгиевна
MEMBER_LEFT | 👤 Пользователь покинул(а) группу
MEMBER_KICKED | 👤 Админ удалил(а) из группы Пользователь
CHAT_NAME_CHANGED | 👤 Анна изменила название чата с «Проект» на «Проект 🚀»
MESSAGE_PINNED | 👤 Анна закрепила сообщение
DATE_SEPARATOR | 📅 Сегодня / Вчера / 11 января 2024

# Пример использования

\*\*
const event: SystemMessageData = {
id: 'sys-123',
type: MessageType.SYSTEM,
eventType: SystemEventType.MEMBER_JOINED,
createdAt: new Date(),
eventData: {
type: SystemEventType.MEMBER_JOINED,
payload: {
userId: 'user-456',
userName: 'Иван Иванов',
joinType: 'invited',
inviterId: 'user-789',
inviterName: 'Анна Петрова'
}
}
};
\*\*

<SystemMessage message={event} />;
// Рендер: "Анна Петрова пригласил(а) в группу Иван Иванов"

# DateSeparator

Маркер даты в потоке сообщений. Используется как целевой элемент для IntersectionObserver.

**Props**

interface DateSeparatorProps {
date: Date; // Обязательная дата для форматирования
className?: string; // Дополнительные CSS-классы
observerId?: string; // ID для отладки (опционально)
}

**Как работает**

// Компонент рендерит невидимый (или стилизованный) маркер:

<div 
  data-date="2024-01-15T10:00:00.000Z"  // Для Observer
  data-observer-id="separator-1704103200000"
>
  <span>Сегодня</span>  // Видимый текст (опционально)
</div>

!! Важно: Сам DateSeparator не позиционируется как sticky. Его задача — быть маркером в потоке, который отслеживает IntersectionObserver в MessagesList.

# StickyDateHeader

Фиксированный заголовок, который «прилипает» к верху чата при скролле.

**_Props_**

interface StickyDateHeaderProps {
date: Date | null; // Дата для отображения (null = скрыть заголовок)
className?: string; // Дополнительные CSS-классы
}

**Поведение**

Состояние | Визуал
date === null | Компонент не рендерится (скрыт)
date !== null | Показывается плашка с датой в 20px от верха контейнера
При скролле | Дата обновляется автоматически через Observer

Пример

<StickyDateHeader date={new Date('2024-01-15')} />;
// Рендер: [ Сегодня ] — зафиксировано сверху

# MessagesList (интеграция)

Контейнер, который связывает все компоненты и управляет логикой отображения дат.

**Props**

interface MessagesListProps {
messages?: Message[]; // Массив сообщений (текст + системные)
className?: string; // Дополнительные CSS-классы
onMessageClick?: (id: string) => void; // Обработчик клика по сообщению
currentUserId?: string; // ID текущего пользователя (для статусов)
}

# Ключевые моменты реализации

IntersectionObserver с rootMargin: '-20px 0px -80% 0px':
Срабатывает, когда сепаратор пересекает линию 20px от верха
Игнорирует элементы в нижней части видимой области
Сортировка видимых сепараторов:

const visible = entries
.filter(entry => entry.isIntersecting)
.sort((a, b) => {
// Ближайший к top: 20px побеждает
const aTop = a.boundingClientRect.top - containerTop;
const bTop = b.boundingClientRect.top - containerTop;
return Math.abs(aTop - 20) - Math.abs(bTop - 20);
})[0];

# Один заголовок вместо наложения:

В потоке: DateSeparator (может быть видимым или маркером)
Сверху: StickyDateHeader с z-index: 50
Конфликтов нет — заголовок всегда перекрывает поток
