🧩 SearchSection
Универсальный контейнер для отображения секций результатов поиска с заголовком и состоянием загрузки.

📦 Пропсы
interface SearchSectionProps {
title: string; // Заголовок секции
children: ReactNode; // Контент (список, грид, и т.д.)
isLoading?: boolean; // Показывать скелетон вместо контента
className?: string; // Доп. классы для кастомизации
showHeader?: boolean; // Скрывать/показывать заголовок (по умолчанию: true)
}

⚡ Пример использования

// Базовое использование
<SearchSection title="Пользователи">
<ContactsListContent contacts={users} />
</SearchSection>

// С загрузкой (скелетон)
<SearchSection title="Группы" isLoading={true}>
<GroupsList groups={[]} />
</SearchSection>

// Без заголовка (если он уже есть выше)
<SearchSection title="" showHeader={false}>
<ContactsListContent contacts={localResults} />
</SearchSection>

// С кастомными стилями
<SearchSection title="Каналы" className={cls.customSection}>
<ChannelsList channels={channels} />
</SearchSection>

🔑 Ключевые моменты

🎨 Условный заголовок | showHeader={false} скрывает заголовок, если он рендерится в другом месте
⏳ Скелетон | При isLoading={true} автоматически показывает UserCardSkeleton
♻️ Переиспользуемый | children принимает любой контент — списки, гриды, таблицы
🧹 Чистый интерфейс | Только отображение, без логики удаления или действий

Когда использовать
✅ Показ результатов поиска в отдельных секциях с заголовками
✅ Единый стиль загрузки для разных типов контента
✅ Композиция: обернуть любой список в стандартизированный контейнер
❌ Не для интерактивных секций (удаление, сворачивание) — для этого создай отдельный компонент
